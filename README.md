🧩 Tetris – Modern Neon Edition

Python • Pygame

A modern Tetris clone built with Pygame to practise game loops, grid-based logic, and collision handling, with extra focus on clean structure and polish.

🧠 What I Learned / Practiced

Game loops and frame-based timing

Grid-based movement and collision detection

Working with rotations and coordinate systems

Managing game state (menu, playing, paused, game over)

Structuring a larger Python project

Adding visual polish and effects in Pygame

✨ Features

Classic 10×20 Tetris grid

All 7 tetrominoes with proper rotation states

SRS wall kicks for smooth rotation near walls

7-bag randomiser for fair piece distribution

Ghost piece to show landing position

Hold piece mechanic (once per drop)

Scoring with:

Line clears

Combos

Back-to-back Tetrises

Level-based speed increase

Neon / glass-style UI with glow effects

Particle effects on line clears

Menu, pause screen, and controls overlay

🖥️ Tech Stack

Python

Pygame

▶️ How to Run
pip install pygame
python main.py
📌 Why This Project

This project was built to go beyond a basic Tetris clone and include real Tetris mechanics like wall kicks, fair randomisation, and hold/ghost pieces. It demonstrates problem-solving, state management, and attention to user experience.
